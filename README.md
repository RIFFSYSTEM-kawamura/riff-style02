# riff-style02（RIFF SYSTEM 公式サイト テーマ）

RIFF SYSTEM の公式サイト [riff-system.com](https://riff-system.com) で使用している WordPress オリジナルテーマです。

- コーポレートサイト（サービス紹介・料金・制作実績・ブログ・FAQ）
- オンライン相談の予約機能（予約枠の管理・Googleカレンダー連携）
- SEO・AI検索への対応：構造化データ（LocalBusiness・FAQPage）、llms.txt の自動更新、IndexNow による公開時のURL通知
- LINE 公式アカウントへの導線と GA4 でのクリック計測

デモサイト：https://demo2.riff-system.com/
